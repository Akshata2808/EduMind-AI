# 🎓 EduMind-AI – AI-Driven Academic Performance Dashboard

EduMind-AI is an intelligent academic performance monitoring platform designed to help educational institutions track student progress, identify academic risks, and support data-driven decision-making.

The platform provides role-based access for Students, Teachers, and Administrators, offering personalized academic insights and centralized performance monitoring through interactive dashboards.

## 🌐 Live Demo

🔗 **[EduMind-AI – Live Website](https://edumind-frontend.onrender.com/)**

## 🚀 Features

- **Role-Based Access Control (RBAC):** Separate access and dashboards for Students, Teachers, and Administrators.
- **Academic Performance Tracking:** Monitor student academic progress and assessment performance.
- **Predictive Score Forecasting:** Estimate future academic performance using machine learning models.
- **At-Risk Student Identification:** Identify students who may require additional academic support.
- **Attendance Monitoring:** Track attendance records and patterns.
- **Personalized Feedback:** Provide students with insights based on their academic performance.
- **Admin Dashboard:** Monitor institutional academic performance.
- **Interactive Visualizations:** Present academic data through charts, graphs, and dashboards.
- **Student Progress Monitoring:** Track performance trends and identify areas for improvement.

## 🎯 Project Objective

The objective of EduMind-AI is to transform traditional reactive academic monitoring into a proactive and data-driven approach.

By integrating academic records, attendance data, assessment results, and predictive analytics, the platform aims to help institutions identify learning gaps early, improve student engagement, and provide timely academic interventions.

## 🛠️ Technologies Used

- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Machine Learning:** Python, XGBoost, CatBoost, LightGBM
- **Authentication:** JWT-based Authentication
- **Access Control:** Role-Based Access Control (RBAC)
- **Data Visualization:** Interactive dashboard visualizations

Refer to the project's dependency files for the exact packages and versions used.

## 📊 System Overview

EduMind-AI follows a data-driven academic monitoring workflow:

1. Academic data is collected from student records, assessments, quizzes, and attendance.
2. The data is processed and analyzed.
3. Machine learning models generate predictive insights.
4. Academic risk indicators and personalized feedback are generated.
5. Role-specific dashboards present insights to Students, Teachers, and Administrators.

## 💻 Getting Started

### Prerequisites

- Node.js
- npm
- Python
- MongoDB

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Akshata2808/EduMind-AI.git
```

**2. Navigate to the project directory**

```bash
cd EduMind-AI
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env` file in the server directory using the provided `.env.example` file.

Configure the required MongoDB connection string, JWT secret, and API keys.

Never commit actual credentials or environment files to GitHub.

**5. Start the application**

Run the appropriate development scripts defined in the project's `package.json`.
